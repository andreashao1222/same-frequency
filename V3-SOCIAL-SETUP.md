# same frequency. — V3 Social setup

1. Replace the files in the existing GitHub repository with this project's files.
2. In Supabase → SQL Editor, run `supabase-social-migration.sql`.
3. Wait for Vercel to deploy automatically.
4. Test:
   - music profile is optional
   - choose Spotify / Apple Music / YouTube Music / Last.fm / SoundCloud / Other
   - submit five artists
   - open the frequency board
   - click another user's report
   - click their music profile link when provided

Do not upload `.env.local` or any secret keys to GitHub.
